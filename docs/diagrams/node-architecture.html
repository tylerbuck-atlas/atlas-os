Atlas OS · Field Nodes ↔ Central Node

How truth flows up, and action flows down

ESP32 field nodes vary by location — each carries the sensors and actuators its room needs — but every one of them speaks to the central node through the same adapter contract. Truth (readings) climbs into governed memory; action (commands) descends only through the Planner's default-deny gate.

truth flow — readings climbing into governed memory action flow — commands descending through the Planner same adapter contract, any node configuration
▲ Truth: sensor → memory (green ①–④)
  1. ① Report. The ESP32 pushes a reading to the adapter over the IoT VLAN, encrypted with its per-device key. Field nodes only ever report in — a compromised node can command nothing.
  2. ② Sync. The adapter — the node's steward — syncs the device into the Device Manager over mTLS, carrying its data class (presence = Class 3, temperature = Class 1).
  3. ③ Persist & publish. The state becomes a versioned fact in Memory (provenance: adapter:…) and a bus event — with Class 2+ payloads redacted before they touch the bus.
  4. ④ Watch. Sentinel consumes the stream: a node going quiet, flapping, or anything anomalous raises an alert.
▼ Action: intent → actuator (amber ❶–❹)
  1. ❶ Propose. You (or the AI, grounded only in Memory/Devices and blind to Class 3) submit a plan — never a direct command.
  2. ❷ Decide. The Planner applies default-deny policy; anything gated waits for your approval. Every plan and step is an immutable audit row.
  3. ❸ Route. The Device Manager — which refuses everyone except the Planner and you — routes the command to the steward adapter.
  4. ❹ Actuate. The adapter drives the ESP32's relay, reads back the new state… and that state re-enters the truth flow at ①.
Security overlays on every arrow: inside the hub, all traffic is mutual TLS with 24-hour certificates issued by Core's CA; identity is cryptographic, revocation is a registry state change. Across the LAN boundary, only the adapter holds the grant, field devices use per-device keys on an isolated VLAN, and firmware updates arrive signed by the same CA (stored content-addressed in Assets, manifests verified by Skills). Nothing anywhere on this diagram can reach the internet — egress is denied at the Docker network layer. Node configurations vary; the contract doesn't: a bedroom sensor puck, a PoE garage controller, and a Zigbee bridge all enter Atlas through the same three verbs — sync, report, actuate.
